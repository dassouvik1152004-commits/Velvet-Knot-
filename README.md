# Product Catalogue Website v2

## New features
- Select company logo directly from your device in Admin > Homepage.
- Select one or multiple product photos directly from your device.
- Product rate field in rupees.
- Discount available checkbox.
- Discount type: percentage or fixed amount.
- Discounted price is automatically highlighted with the original price struck through.
- Product details show all selected photos.

## Run
Keep `index.html`, `style.css`, and `app.js` in the same folder and open `index.html` in Chrome.

## Note
This prototype stores data in browser localStorage. For a real online website, connect it to Supabase for shared database/image storage and admin authentication.
